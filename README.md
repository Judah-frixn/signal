# Signal — India Business Intelligence

A premium, modern editorial business intelligence dashboard for Indian startup funding, D2C brand launches, SaaS & B2B tech updates, B2C consumer trends, financial markets, and AI tool insights.

## Features
- **Modern Editorial Layout**: Designed with a newspaper-aesthetic style using clean typography, double rules, and warm paper palettes.
- **Credit-Efficient NewsData.io API**: Optimized queries consolidating multiple categories to save API call credits.
- **Dynamic Client-Side Tagging**: Automatically tags articles in real-time.
- **Responsive Newspaper Grid**: Elegant 2-column editorial grid for desktop and single-column for mobile.
- **Clean Article Digests**: Concise, readable story cards with explicit links to full articles on source websites.

## Setup
1. Clone the repository.
2. Open `index.html` in your browser.
3. Configure your free **NewsData.io** API key in the Setup panel.
